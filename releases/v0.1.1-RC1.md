## RC1 Scalability Checklist

**Scenario:** 500 skills · 100 workflows · 80 packs · 40 agents · 20 compilers · 100+ capabilities

| # | Question | Answer | Mitigation if no |
|---|----------|--------|------------------|
| S1 | Will folder structure work? | **Yes** | Self-contained packs; domain subdirs |
| S2 | Will routing work? | **Yes** | Capability-first (ADR 0009) |
| S3 | Will indexes work? | **With tooling** | Generated indexes — ADR 0012, v0.2 |
| S4 | Will contracts parse uniformly? | **Yes** | Knowledge Contract + schema |
| S5 | Will validation scale? | **With tiering** | Tiered validation — ADR 0012, v0.5 |
| S6 | Will compilers scale? | **With registry** | `compilers/manifest.yaml` — v0.5 |
| S7 | Can packs publish independently? | **Yes** | ADR 0002 |
| S8 | Will evidence model prevent hallucination drift? | **Yes** | ADR 0010; `confidence: Unknown` blocks stable |
