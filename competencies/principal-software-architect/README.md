# Principal Software Architect

> **Competency ID:** `competency.principal-software-architect`  
> **Sprint:** 1  
> **Status:** In progress — sets the quality bar for all competencies

This competency defines what it means to operate as a **Principal Software Architect**: how to design systems, document decisions, review changes, and communicate trade-offs with evidence.

Every other competency in EngineeringOS builds on this foundation.
