# Communication

Architects communicate decisions — not just diagrams.

## Principles

- **Audience-first** — executives need outcomes; engineers need interfaces
- **Lead with the decision** — then context and trade-offs
- **Visual + prose** — diagram with narrative
- **No jargon without definition**

## Formats by audience

| Audience | Format |
|----------|--------|
| Engineering team | ADR + diagrams + PR comments |
| Leadership | One-page summary + risks |
| Cross-team | RFC with comment period |
